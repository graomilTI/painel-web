Favorito: copiar o token do GRM

Arraste o botão abaixo para a barra de favoritos do navegador (ou crie um favorito e cole o código da seção "Sem arrastar" como URL).

Copiar token GRM

Uso diário (depois da meia-noite)

  1. Entre no GRM (grmserver.com.br) pelo navegador e espere o painel abrir.
  2. Clique no favorito Copiar token GRM. Ele copia o token e mostra até quando vale.
  3. No servidor, rode como grao100: 
    cd /home/grao100/painel-scripts/grm-sync && /opt/node22/bin/node grm-token-cache.js salvar
  4. Só quando aparecer Cole o token e tecle Enter, cole (Ctrl+V) e tecle Enter.

Cuidado: o token vale como senha da conta do GRM. Ele só vai para a área de transferência do seu computador, nada é enviado pela internet. Não cole no chat, e-mail nem em outro prompt do servidor.
